Cách đưa Website này lên GitHub Pages

Chỉ mất 2 phút, miễn phí 100%, có link web công khai ngay

1

Tạo Repository mới trên GitHub (Public)

Đăng nhập github.com → Bấm New Repository → Đặt tên → Chọn chế độ Public (Bắt buộc để chạy Pages miễn phí).

2

Tải file index.html lên bằng trình duyệt

Trong repository vừa tạo trên web (Chrome/máy tính), bấm Add file → Upload files → Tải file index.html lên → Bấm Commit changes.

3

Kích hoạt GitHub Pages

Vào tab Settings → mục Pages ở menu trái → tại Branch chọn main, folder chọn / (root) → Bấm Save.
