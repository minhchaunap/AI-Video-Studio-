Cách đưa Website này lên GitHub Pages

Chỉ mất 2 phút, miễn phí 100%, có tên miền .github.io ngay

1

Tạo Repository mới trên GitHub

Đăng nhập github.com → Bấm New Repository → Đặt tên (VD: ai-video-studio) → Chọn chế độ Public.

2

Tải file index.html lên

Trong repository vừa tạo, bấm nút Add file → Upload files → Kéo thả file index.html (bấm nút "Tải mã nguồn" ở góc trên trang để lưu về máy) → Bấm Commit changes.

3

Kích hoạt GitHub Pages

Vào tab Settings của repo → Chọn mục Pages ở menu bên trái → Tại Branch chọn main (hoặc master), thư mục chọn / (root) → Bấm Save.

Sau 1 phút, trang web của bạn sẽ hoạt động tại link:
https://<username>.github.io/<tên-repo>/
